To test the code in EustisSetup.java we must use the driver and other supporting files provided by Dr. Andrew Steinberg. The first methods are simple print statements, and ticket systems, but the real fun begins with the "category" method on line 75. In this method, we parse the input file, arcade.in using the scanner method. We replace all "_" characters in arcade.in with blank space characters, and we extract the numbers from it, converting them into double values that we can subsequently use for calculations. After calculating the average revenue per recipient (RPR) and the machine with the high RPR value, we use print statements to neatly display these values.
